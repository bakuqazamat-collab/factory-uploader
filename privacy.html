Privacy Policy

Factory Uploader

Factory Uploader uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy also applies.

Who uses the app

The app is used only by its owner, on the owner's own computer, for the owner's own YouTube channels.

What data we access

  • An OAuth access token for the owner's Google account, with permission to upload and manage videos on the owner's channels.
  • Basic metadata of the owner's own channels and videos (titles, IDs, publish status, view counts).

How we use it

Only to upload the owner's videos, set thumbnails and metadata, schedule publishing, and show the owner the status of their own videos.

Storage

OAuth tokens and data are stored only locally on the owner's computer. Nothing is stored on any server. Locally cached API data is refreshed or deleted within 30 days.

Sharing

We do not sell, share, transfer or disclose any user data to third parties, and we do not use it for advertising. We do not use cookies or tracking, and we do not place or read any information on users' devices other than the locally stored OAuth token.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

You can revoke the app's access at any time via the Google security settings page. To delete locally stored data, delete the token file on the computer or contact us.
